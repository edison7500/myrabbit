# Native tab templates

These transparent PNG templates are exported from the named `ChartNoAxesCombined`, `Radio`, `Compass`, and `Settings2` icons in `lucide-react-native` 1.41.0, under the included ISC license.

UIKit tab items require image sources; Expo Router does not accept arbitrary React Native SVG components as native tab icons. Other UI continues to use named imports from `lucide-react-native`.

Each image is 24 pt with 1×, 2×, and 3× variants, white strokes, no fill, round line caps/joins, and the original 24×24 view box. Default stroke width is 1.8; selected stroke width is 2.2. Native template rendering applies the current theme's tint.
