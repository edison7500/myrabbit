# Rybbit API

`request.ts` provides Bearer-authenticated JSON requests, cancellation, bounded timeouts and typed errors. Browser cookies are omitted. `client.ts` loads credentials from platform storage for site discovery, Dashboard overview requests and bucketed traffic trends. Date ranges are serialized with Rybbit Web’s inclusive calendar, relative-minute, all-time, adaptive-bucket and IANA-timezone semantics. External payloads are validated before reaching the UI.

`analytics-context.ts` defines the credential-free shared query context and deterministic request identity. `breakdown.ts` implements the source-verified Referrers, Pages, Browsers and Countries dimension request, runtime response validation and page-number pagination. UI support for these requests is implemented separately.

iOS widgets reuse the overview requests, Dashboard number formatting, and `metricChange` calculations. Matching unfiltered Today responses are shared without extra requests; other ranges or filters trigger a separate unfiltered, fixed-calendar-day overview and previous-period pair. No credentials or raw responses enter the widget cache. Nullable no-session overview ratios/duration are normalized to unavailable fields while zero counts remain data, matching the [official metrics definitions](https://github.com/rybbit-io/rybbit/blob/9cee0e9007ecb574533a4a2f28623b78f84b18a1/server/src/services/siteMetrics/siteMetrics.ts); older versions may omit optional metrics.

Connection setup tests the unsaved draft via `GET /api/organizations` with a 10-second timeout before allowing SecureStore persistence. No credentials are saved by the test itself.

Contracts: https://rybbit.com/docs/api/organizations/list, https://rybbit.com/docs/api/organizations/sites, https://rybbit.com/docs/api/overview/overview and https://rybbit.com/docs/api/overview/time-series.

Dimension planning: [source-verified MVP dimension contract](./explore-contract.md) records the pinned upstream revision, Sessions semantics, attribution, sorting, pagination and display behavior for Referrers, Pages, Browsers and Countries. Dashboard now previews five Referrers and opens a paginated detail screen. Explore now includes Browsers and Countries plus additional technology/location dimensions. Pages UI and full live-instance numerical verification remain outstanding.

`realtime.ts` validates `GET /api/sites/:site/sessions` with `past_minutes_start=30`, `past_minutes_end=0`, `page=1`, and `limit=100`. It uses the selected server/site independently of the Dashboard date range, loads credentials only for each request, and sorts by latest session activity. Nullable metrics display as unknown rather than zero. Missing or malformed IDs/timestamps reject the payload with a server-version message. The Realtime table polls every 30 seconds only while focused and active, cancels outstanding requests when paused, and retains the last successful response on errors. This bounded table is the latest 100 sessions, not an exhaustive visitor count. Green dots use a five-minute activity window. Anonymous names are generated locally, not supplied by the API.

Realtime contracts: [Sessions](https://rybbit.com/docs/api/sessions/list), [common relative-time parameters](https://rybbit.com/docs/api/getting-started), and [polling guidance](https://rybbit.com/docs/api/live-feed). Live compatibility with older self-hosted versions still requires verification against the configured server.

Session timestamps: `session-timestamp.ts` normalizes timezone-less SQL timestamps as UTC, matching [Rybbit SessionCard](https://github.com/rybbit-io/rybbit/blob/master/client/src/components/Sessions/SessionCard.tsx). Explicit ISO offsets remain authoritative. Both start-time display and the five-minute activity indicator use the normalized instant; the activity clock advances on polling attempts even if the last successful data is retained.

Connection removal is entirely local: SecureStore (native) or credential memory (web) and the saved selection are cleared. The API client has no site-deletion operation. Site selection and analytics use read-only requests; removing a connection never deletes Rybbit sites/data or revokes the server-side API key.

`explore-charts.ts` implements Explore’s Technology, Locations, Events and Weekly Trends cards. Metric rankings use `/metric` with `browser`, `device_type`, `operating_system`, `dimensions`, `country`, `region`, `city`, `language` or `timezone`; each collapsed summary fetches up to 100 rows. Locations previews five rows; expansion follows every next page with the same context and abort signal, deduplicates raw values and caches the complete result until the category/context changes or refreshes. Events use `/events/names` (`eventName`, `count`), `/events/outbound` (`url`, `count`) and `/events/autocapture?type=button_click|form_submit|copy` (`value`, `count`). All preserve the selected context and use the shared authenticated request boundary. Each card isolates errors and cancels superseded requests. Older servers that lack autocapture endpoints show a retryable error instead of fabricated zeroes.

Weekly Trends requests `/overview/time-series` with `bucket=hour` independently of the Traffic chart’s adaptive bucket. Time-series SQL timestamps represent wall-clock buckets in `time_zone`; explicitly zoned ISO timestamps are converted to that timezone. Monday–Sunday × 24-hour cells average all returned buckets for that weekday/hour, matching Rybbit Web. Missing metrics/buckets remain distinct from real zeroes.

Verified against official Rybbit source on 2026-10-15: [metric query](https://github.com/rybbit-io/rybbit/blob/master/server/src/api/analytics/getMetric.ts), [event names](https://github.com/rybbit-io/rybbit/blob/master/server/src/api/analytics/events/getEventNames.ts), [outbound](https://github.com/rybbit-io/rybbit/blob/master/server/src/api/analytics/events/getOutboundLinks.ts), [autocapture](https://github.com/rybbit-io/rybbit/blob/master/server/src/api/analytics/events/getAutocaptureEvents.ts), [hourly query](https://github.com/rybbit-io/rybbit/blob/master/server/src/api/analytics/getOverviewBucketed.ts), [Weekly Trends UI](https://github.com/rybbit-io/rybbit/blob/master/client/src/app/%5Bsite%5D/main/components/sections/Weekdays.tsx). These source checks do not establish a minimum compatible self-hosted version.

Dashboard metric details reuse `/overview` and `/overview/time-series` for all six KPIs. The traffic parser preserves and validates optional `sessions`, `pages_per_session`, `bounce_rate` (0–100) and `session_duration` fields alongside Users/Pageviews. Details read the selected field directly; they do not derive ratios or durations from other totals. A missing selected series on an older self-hosted server produces a retryable compatibility message; unavailable Yesterday metrics leave the current series visible. Verified against the [official time-series reference](https://rybbit.com/docs/api/overview/time-series) and [bucketed query](https://github.com/rybbit-io/rybbit/blob/master/server/src/api/analytics/getOverviewBucketed.ts) on 2026-10-20; this does not establish a minimum server version.
